## ۴. رخداد امنیتی و پاسخ (درس‌آموخته)

**رخداد:** بک‌آپ حاوی کلید ارشد به‌اشتباه commit و push شد.
**پاسخ (کمتر از ۳۰ دقیقه):**
1. حذف از index + `.gitignore` برای `data/` و `backups/`
2. پاک‌سازی داده محلی و bootstrap تازه (= کلید ارشد جدید)
3. بازنویسی کامل تاریخچه با `git filter-repo` + force push
4. تأیید: هیچ فایل حساس در تاریخچه باقی نماند
**درس:** قبل از هر commit، `git status`؛ هرگز `git add -A` بدون بازبینی.
